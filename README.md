# 熊酒馆 · BearTRPG

在浏览器中创作、准备和游玩自己的桌游。此仓库是 **0.8.1 纯编辑器版**：首次打开为空白桌面，游戏库从空目录开始，模组由作者自行制作或导入。

## 快速开始

需要 Node.js **24.14 或更新的 24.x**、npm，以及支持 WebGL 的现代浏览器。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。开发服务器会同时启动前端和本机 API；默认端口为 5173 和 3001。Windows 用户安装依赖后也可双击 `启动熊酒馆.cmd`。

```sh
npm test
npm run build
npm start
```

生产模式先执行构建，再通过 <http://127.0.0.1:3001> 访问完整编辑器。本机版由同一服务提供 `/api` 接口；在线静态版使用下文的浏览器存储适配。

## 在线编辑器

入口：[熊酒馆纯净桌游编辑器](https://ghostbear111.github.io/BearTRPG/)

`npm run build:pages` 生成 `artifacts/pages-editor/`，可部署在 HTTPS 静态网站的任意子目录。在线版首次打开同样为空白桌面，游戏库没有预装剧情，不包含《星海群侠传》。基础棋子、骰子和道具模板保持可用。

桌面与存档仍保存到浏览器，物件模板、作品版本和图片改用 IndexedDB 保存。上传图片不会发送到 GitHub 或其他服务器；角色卡、文字 APNG、自定义物件、模组导入导出和编辑后试玩可使用。首次打开会先启动编辑器目录内的 Service Worker，再加载工作区；请使用允许本站保存数据的现代浏览器。

在线版的数据属于当前设备和浏览器，清理站点数据会清除这些内容，请用导出功能备份。在线版不提供云同步和服务器模型代理；AI 主持需本机版或独立后台。

本仓库通过 GitHub Actions 自动构建并部署到 GitHub Pages。提交到 `main` 分支后，`Deploy BearTRPG editor` 工作流会执行 `npm ci` 和 `npm run build:pages`，仅发布 `artifacts/pages-editor/` 中的静态网页；也可在 Actions 中手动运行。服务器代码、测试和本机数据库不会进入网页部署包。Pages 的发布来源设为 **GitHub Actions**。

## 创作与游玩

1. 在编辑模式创建桌面，设置场景板尺寸、网格和视角，从物件库取用棋子、骰子、标记、卡牌、牌堆和地形。
2. 在物件后台制作自己的模板，配置外观、符号骰面、游戏移动范围和操控权限。角色卡支持肖像、属性、资源条、自定义字段和主持私密资料。
3. 使用故事编辑器编写章节、场景、任务、条件与检定；剧情工具可进一步制作坐标地图、NPC、嵌套事件脚本、技能骰组及角色成长。
4. 保存作品并试玩。游戏模式运行独立的对局快照，保留移动限制、交互、回合战斗、投骰和存档续玩。
5. 在游戏库导入或导出 `.adventure.json` 模组；RPG 数据包使用 `{ "format": "bear-rpg-content", "version": 1, "db": ... }`。重复导入会定位已有作品。

角色卡工具与动态文字 APNG 工具均已整合，图片会持久保存到本机资源库。可以连接 Ollama 或兼容 OpenAI 接口的语言模型作为 AI 主持。

## 数据与内容

- 桌面、编辑稿、跑团存档及视角保存在当前浏览器中；使用导出功能备份和迁移。
- 物件模板、作品版本及上传的图片保存在本机 `data/` 目录中；首次运行自动创建。完整迁移时同时保留此目录和浏览器导出的存档。
- 模型 API 密钥仅在当前页面内存中使用。
- 本仓库不包含预装游戏剧情、角色数据库、音乐、作者存档或本机数据库。`tests/fixtures/` 只用于自动化回归测试，不进入发布包或游戏库。
- 独立的浏览器缓存命名空间避免与原开发版混用编辑稿。需要其他项目内容时，请通过模组导入功能加入。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `src/components/` | 三维桌面、编辑器、角色卡、剧情工具与游玩界面 |
| `src/lib/` | 物件操作、规则、剧情运行、骰组、版本与存档模型 |
| `server/` | 本机资源、物件模板、作品版本与模型代理 API |
| `public/modules/bear-tavern/` | 角色卡与文字 APNG 工具 |
| `public/assets/` | 可自定义的骰面与基础视觉素材 |
| `tests/` | 测试数据与浏览器验证页面 |
